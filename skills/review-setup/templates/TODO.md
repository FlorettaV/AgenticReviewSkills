# Open items

**<operator> ticks these**, once an item is either understood or handled
somewhere else — a ticket, a comment, a fix. A ticked item stays where it is;
this file is not a backlog that gets pruned.

- **`R`** — found by the review that was asked for.
- **`A`** — additional. Noticed while doing something else, parked here rather
  than derailing the thing in hand.

Numbers continue from the highest in the file and are never reused. Each line
names where it came from:

```
- [ ] **R1** (MR 13) <the finding's title>
- [ ] **A2** (MR 13) <something noticed while reviewing MR 13>
- [ ] **A3** (–) <something noticed outside any review>
```

New MRs are added directly below, newest first.
